# Planimetry - Библиотека для вычисления площадей геометрических фигур

Легковесная библиотека на C# для вычисления площадей различных геометрических фигур.

## Возможности

- Вычисление площади круга по радиусу
- Вычисление площади треугольника по трем сторонам  
- Проверка треугольника на прямоугольность
- Простое добавление новых фигур
- Полиморфное вычисление площадей без знания конкретных типов фигур
